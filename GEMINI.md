# Project Guidelines & Rules (Ponytail)

This project follows the **Ponytail** minimalist development guidelines (`DietrichGebert/ponytail`).

- **Core Principle**: "The best code is the code you never wrote."
- **The Ladder**:
  1. YAGNI: Question whether the code needs to exist.
  2. Reuse: Reuse existing utilities, hooks, components, and patterns in the repo.
  3. Standard Library: Reach for built-in JavaScript/Node APIs before writing custom utilities.
  4. Native Platform: Use browser/platform native capabilities before third-party libraries.
  5. Installed Dependencies: Leverage existing installed dependencies; do not add new npm packages unnecessarily.
  6. One Line: Prefer single clean expressions over multi-layer abstractions.
  7. Minimum Viable: Write the shortest, cleanest solution that works.
- **Safety First**: Never sacrifice security, error handling, trust-boundary validation, or accessibility.
